What a computer-use cache actually does

Record real computer actions

The agent logs clicks, keystrokes, navigation, and visual context while operating a real browser or desktop environment.

Normalize and store action traces

Those steps are distilled into a reusable action trace — a durable computer-use cache instead of brittle scripts.

Replay and adapt

On repeat runs, Super reuses the cache and adapts only where the UI or data changed.

Lower cost, higher reliability

Fewer full explorations means fewer tokens, less vision work, and fewer failures on known paths.
